## تکنیکی اسٹیک

- **فرنٹ اینڈ:** React.js (Vite)
- **ڈیزائن:** Vanilla CSS (US Government style)
- **زبان:** اردو (RTL)

## شروع کرنے کا طریقہ

```bash
cd client
npm install
npm run dev
```
